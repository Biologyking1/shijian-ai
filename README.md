# 食鉴 AI

食鉴 AI 是一个面向农客松的 Streamlit 应用。打开首页后，可按实际情况选填个人信息、饮食限制和消费偏好，也可跳过。桌面和手机首页都将「预包装食品」放在「现制奶茶」上方。两个专区共用偏好，各自保留候选商品。

点击照片卡片即可进入专区。手边没有照片时，点「试读一瓶柠檬茶的标签」可直接用演示数据比较半瓶和整瓶的摄入量。已有食品时，首页提供「继续查看我的食品」。也可点「试一杯伯牙绝弦」查看收录配方的等级和每杯能量。

在食品的「食用量与建议」中，展开「猜一猜」可先估算半包的摄入量，再看标签上的原数与换算过程。包装单位不匹配时，可用两倍标签份量出题。有同杯型、同温度且能量已披露的甜度配方时，奶茶查询和 DIY 结果也可竞猜每杯能量怎么变。所有问题都可跳过。系统开启「减少动态效果」时，新增的切换、展开和图表动效自动关闭。

全站视觉在 Streamlit 中适配自 Nova Studio 的免费健康模板 Chard。首页横幅为摄影师 ha ha 拍摄的超市食品货架，按 Pexels 许可用于本项目。[Framer 模板](https://www.framer.com/marketplace/templates/chard/) · [模板设计指南](https://chard.framer.website/design-system) · [货架原片](https://www.pexels.com/photo/shelves-in-grocery-store-16211537/) · [照片许可](https://www.pexels.com/license/)

## 现制奶茶

此专区接收杯贴、单杯订单、品牌营养卡，以及对应的品牌、品名和点单规格。拍照前可裁去姓名、手机号及取餐码。

| 入口 | 使用方法 |
| --- | --- |
| 查一杯奶茶 | 输入品名或拍摄杯贴，核对识别值后查询。结果注明地区、规格、资料日期和来源。点「查询营养资料」可从霸王茶姬中国大陆健康计算器查询当前配方。其他收录资料可直接查阅，未收录的饮品可上传或手填门店的营养卡。 |
| DIY 点单 | 从已查到的规格开始，调整糖度、杯型、冰量或加料。可按需查询霸王茶姬官方改配数据。有门店公布的小料营养或差价时可按提示试算。没有资料的项目显示待补。 |
| 比较与推荐 | 加入多杯，选择同品牌不同品类，或跨品牌同品类。填写实际人民币售价和口味，按共享偏好的权重查看候选排序与理由。营养维度可选个人指标、每杯能量或同一体系已公布的等级。 |
| 个人茶饮账本 | 记实际茶饮支出、收入或退款，按月看明细、结余和每周支出图。图表按周一至周日汇总所选月内的支出。从 DIY 带入饮品后仍可核对实付金额。记录保存在当前浏览器的 IndexedDB，支持导出与合并恢复 JSON，换设备时请带上备份。 |

杯贴用于辨认饮品与规格。公开资料按完整配方区分，原配方、最高标示值及资料未披露的条件均会标注。霸王茶姬联网查询仅发送品名与所选配方，结果最多缓存一小时。网页同时附带已核对的菜单快照，可在品牌服务不可用时查看。[霸王茶姬健康计算器](https://qmproductcomput.bwcj.com/)

品牌公开等级保留原分级体系。用户补录营养卡时，可按中国营养学会团体标准 T/CNSS 045—2025 表 1 推算，每 100 mL 需要果糖、葡萄糖、蔗糖和麦芽糖之和、饱和脂肪、反式脂肪酸，以及甜味剂使用情况。资料不足时页面列出缺项。上海 2024 年试点的历史记录标有来源与日期。[中国营养学会标准原文](https://www.cnsoc.org/notice/files/%40CmsXh_ec3afa08-6f83-482b-aa2c-d8526166f73e.pdf) · [上海市政府试点说明](https://www.shanghai.gov.cn/nw4411/20240327/e8be271a682a4dfe907fbeb0d39d8b95.html)

## 预包装食品

此专区接收预包装商品的包装、背标、价签或货架照片，以及对应的商品资料。

| 入口 | 适合的问题 | 怎么用 |
| --- | --- | --- |
| 单品解读 | 我这次会吃进去多少？包装说法有依据吗？ | 读取并核对一款食品，拖动实际份量滑块或输入克数、毫升数，查看标签声称、配料百科和饮食提醒。糖有单列数值时显示等重方糖，每块按 4 克演示。 |
| 多款比较 | 按我的偏好，几款食品里更倾向哪一款？ | 在消费偏好中设置营养、实惠、口味的权重，上传多款商品照片或逐款手动录入，确认每款数据后查看匹配度及原因。可从单品页将已核对的商品加入同一清单。 |
| 货架购物助手 | 现场有货且符合我的预算和饮食限制的商品有哪些？ | 拍一张货架照，或一起上传货架、价签与近照，每批最多 8 张。核对规格和整包售价，设置单包预算，勾选缺货或不考虑的商品后查看剩余选择。 |

在「多款比较」选择「体验三款演示饮料」，可离线体验价格、权重和排除条件改变后的结果。加入已核对的实际商品后，比较使用实际商品。现场拍摄、价格和营养数据均可在保存前改正。

单品解读提供半包、整包与滑块换算，整包净含量和换算单位相符时显示份量示意。含糖量只使用标签单列的糖数值。食品和茶饮均可并排查看两款候选，超过两款时可切换对照对象。

## 数据与判断依据

- **偏好档案**可在本次会话复用，并通过导出、导入 JSON 跨会话使用。档案含个人饮食偏好或限制，请自行保管。匹配度是一种根据用户权重计算的选择模型。
- **价格与营养性价比**使用可核实的人民币整包价。货架上邻近价签、会员专享价或多件促销需手动确认。有足够数据时，按包装原状每 100 克或毫升的个人营养偏好分，除以购买该份量的价格，得到偏好分/元，同时可查看蛋白质或膳食纤维克数/元。不同标准份量应分别比较。缺少必要的营养数据、规格或价格时，页面指出待补项目。
- **营销声称**按明确识别的包装原话与营养数据、配料交叉核对。结果附带证据或待补信息，规则覆盖范围以页面说明为准。
- **配料百科与饮食提醒**支持查看配料的常见作用、来源及注意事项，标记过敏原、特殊饮食和自选关注项。标签信息不足时需回看包装或联系厂家。
- **原图核对**保留每次识别的原始照片。展开「查看数据与原始照片」，选择具体字段查看来源图。自动定位缺失时，可人工关联。清晰度不足时可通过「补充这款商品的原图」追加近照并手动修正。原始识别值和人工修订可分别回看。

## 在本机运行

使用 Python 3.12 或更高版本。在项目目录运行以下命令。如果使用 Anaconda，可在已激活环境的 Anaconda Prompt 中执行。

```powershell
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

打开终端显示的本机地址。选择「预包装食品 → 单品解读」，点「载入示例」，再点「确认标签并生成建议」，即可在没有模型密钥时试用。将柠檬茶的食用量选为半包，页面会按演示标签显示 20 克碳水化合物，糖一栏显示缺少数据。

## 启用百灵图片识别

在上传区点击「打开相机拍照」，允许浏览器使用摄像头，再对准标签拍摄。照片会自动加入本次识别，可逐张移除，也可以再次打开相机补拍。实拍照片和相册选图合计最多三张，选好后点击「识别照片」。手机扫码使用时，请打开部署后的 HTTPS 地址并允许相机权限。 [浏览器摄像头权限说明](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia)

使用赛事账户登录蚂蚁数科 MaaS，在模型页点「API 调试」→「创建 API Key」。将项目内的 `.streamlit/secrets.toml.example` 复制为同目录的 `secrets.toml`，只需在 `LING_API_KEY` 的双引号之间填入该账户的密钥。如果已有 `secrets.toml`，在原文件中更新这三项即可。 [赛事平台百灵视觉模型与调用示例](https://maas.antdigital.com/models/modelservice-1793847340277001619)

```toml
LING_API_KEY = ""
LING_BASE_URL = "https://maas-api.antdigital.com/v1"
LING_MODEL = "ling-3.2-flash"
```

保存后重启应用。在「单品解读」中上传一张食品背标，点「识别照片」，对照原图核对计量基准、能量和钠值。也可以通过同名环境变量配置，环境变量优先。如果使用独立的百灵开发者平台账户，请使用该平台的密钥、地址 `https://api.ant-ling.com/v1` 和模型 ID `Ling-3.2-flash`。 [百灵开发者平台接口说明](https://developer.ant-ling.com/zh-CN/docs/api-reference/chat/openai/)

默认沿用本机网络代理。如果模型列表可访问、识图请求却被代理中断，可在 `secrets.toml` 中加入 `LING_DIRECT_CONNECTION = true` 让模型请求直接连接官方接口。每次识别最多等待 240 秒接收下一段响应。

用户可以一次上传同一食品的最多三张 JPG、PNG 或 WebP 照片，每张最多 8 MB。应用会去除照片元数据，再发送给配置的模型。年龄、性别、身高、体重和健康选项仅保存在当前网页会话中。应用没有持久化问卷、照片或结果的数据库。

## 部署链接和二维码

将项目放到 GitHub 仓库，然后在 Streamlit Community Cloud 选择仓库、分支和入口文件 `app.py`。模型配置填写在部署页面的 **Secrets** 中。网页可以在没有模型密钥时作为演示模式启动。部署成功后，把实际的可访问地址加入 Secrets，例如 `PUBLIC_APP_URL = "https://你的子域名.streamlit.app"`。刷新网页，展开「分享网页 · 二维码」即可下载 PNG。用手机验证链接是否可以访问。 [Streamlit 部署文档](https://docs.streamlit.io/deploy/streamlit-community-cloud/deploy-your-app/deploy)

`secrets.toml` 已列入 `.gitignore`。赛事展示前，用比赛将使用的网络和账户检查真实照片识别、网页可访问性及模型额度。
